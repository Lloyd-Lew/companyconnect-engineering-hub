# Security Policy

The Engineering Hub is a static technical proof site. It contains no customer portal, authentication, form capture, database, runtime API, or secret configuration. Do not commit customer data, credentials, tracking tokens, private URLs, or confidential technical material.

Report a potential security concern privately to [letsconnect@companyconnect.tech](mailto:letsconnect@companyconnect.tech?subject=Security%20report%20-%20CompanyConnect%20Engineering%20Hub). Include the public URL, affected path, concise safe reproduction, and impact; do not disclose sensitive material in a public issue.
